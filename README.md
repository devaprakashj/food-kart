# 🍔 FoodKart | Premium Food Delivery Experience

A full-stack, high-performance food delivery application built with **React.js**, **Tailwind CSS**, and **Firebase**. This project features a premium UI/UX inspired by top-tier food delivery platforms, offering a seamless experience from browsing to checkout.

🚀 **Live Demo:** [https://devaprakashj.github.io/food-kart/](https://devaprakashj.github.io/food-kart/)

---

## ✨ Features

- **🛍️ Premium UI/UX**: Modern, Zomato-inspired design with sleek animations (Framer Motion) and custom branding.
- **🔐 Robust Authentication**: Secure Google Sign-In and Email/Password authentication powered by **Firebase Auth**.
- **🥘 Dynamic Menu**: Real-time restaurant listing and menu fetching from **Cloud Firestore**.
- **🛒 Persistent Cart**: Synchronized shopping cart that persists across devices for logged-in users.
- **📜 Order History**: View previous orders with status tracking and detailed item summaries.
- **📱 Responsive Design**: Fully optimized for mobile, tablet, and desktop views.
- **⚡ SEO Optimized**: Structured data and meta tags for maximum search engine visibility.

---

## 🛠️ Technology Stack

- **Frontend:** React 19, Vite, Tailwind CSS 4.
- **Backend:** Firebase (Authentication, Firestore, Analytics).
- **Icons:** Lucide React.
- **Animations:** Framer Motion.
- **Deployment:** GitHub Pages.

## 🏗️ Getting Started

### Prerequisites

- Node.js (v18+)
- npm or yarn
- Firebase account

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/devaprakashj/food-kart.git
   cd food-kart
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Set up Firebase:**
   - Create a project on [Firebase Console](https://console.firebase.google.com/).
   - Copy your Web Config and replace the credentials in `src/firebase.js`.

4. **Run in development mode:**
   ```bash
   npm run dev
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```
